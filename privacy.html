Privacy policy: Channel Uploader

Last updated: 29 October 2026

What the tool is

Channel Uploader is a command-line program run by a YouTube channel owner on the owner's own computer. It has one user: the channel owner.

What it accesses

With the owner's permission, given through Google sign-in (OAuth 2.0), the tool uses the YouTube Data API and the YouTube Analytics API to:

  • upload videos to the owner's channel and set their title, description, tags, thumbnail and playlist;
  • read the owner's own channel and video statistics (views, watch time, audience retention).

It uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What it collects about other people

Nothing. The tool does not collect, store, sell or share any personal information about viewers or any other person. It reads only aggregate statistics about the owner's own videos.

Where data is stored

The sign-in token is stored only on the owner's computer, in a file readable only by the owner. No data is sent anywhere except to Google's YouTube API servers.

Revoking access

The owner can revoke the tool's access at any time at myaccount.google.com/permissions; the stored token then stops working.
